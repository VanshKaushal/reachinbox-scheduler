## Reproduce

Follow the README to start infrastructure and create both isolated test databases. Then run:

```sh
npm run check
npm run test:integration
npm run test:e2e
node scripts/accessibility.mjs
npm audit
docker build -t reachinbox-scheduler:local .
```

Integration and browser suites need network access to Ethereal, plus running local MySQL, Redis and Elasticsearch. Browser checks use Playwright's Chromium headless shell; install it with `npx playwright install chromium --with-deps` if it is not present. The standalone accessibility script targets the development frontend at `http://localhost:5173`.

Reports/logs/videos under `artifacts/` are gitignored and regenerated locally. Curated product screenshots are committed under `docs/screenshots/`.

## Assumptions and limits

- The brief included no actual Figma URL; the interface uses an original design.
- Quotas use fixed UTC hours and count attempted dispatches conservatively.
- SMTP cannot atomically commit acceptance with SQL; ambiguous outcomes become `delivery_unknown`, with automatic resend prevented.
- Queue timing is at or after the requested time. Provider outages, throttling and process downtime can delay delivery.
- Indexing is eventually consistent. Search reports unavailability while normal scheduling/delivery remains usable.
- The 1,001-recipient check verifies persistence and queue handoff; it is not a claim that 1,001 SMTP messages were delivered in the test.
- GitHub collaborator invitations are pending until reviewers accept. A personal private repository uses GitHub's standard collaborator write role.
- Public deployment and account consent remain separate from local test success.
